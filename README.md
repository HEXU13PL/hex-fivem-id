# 🛠️ FiveM Identifier Tools

Strona internetowa umożliwiająca szybką konwersję i sprawdzanie identyfikatorów graczy w FiveM (Steam ID 64, Steam HEX, Discord ID, License).

🌐 **Bezpośredni link do narzędzia:**  
👉 **[https://hex-id.chickenkiller.com/](https://hex-id.chickenkiller.com/)** 👈

---

## 📖 Jak używać narzędzia?

### 1. Wyszukiwanie identyfikatora gracza
1. Wejdź na stronę [hex-id.chickenkiller.com](https://hex-id.chickenkiller.com/).
2. Wklej identyfikator gracza w pole wyszukiwania (np. `steam:110000100000000` lub link do profilu Steam / ID Discorda).
3. Kliknij przycisk **Szukaj / Konwertuj**.
4. System automatycznie wygeneruje pozostałe formaty identyfikatorów.

### 2. Kopiowanie danych do banów / permisji FiveM
* Wybierz potrzebny format (np. `Steam HEX` lub `Discord ID`).
* Kliknij przycisk **Kopiuj** obok wygenerowanego rekordu.
* Wklej gotowy identyfikator do plików konfiguracyjnych serwera (`server.cfg`, baza danych MySQL, banlista TXAdmin itp.).
